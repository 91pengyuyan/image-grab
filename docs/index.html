立即安装 查看功能

为什么需要图提取？

做电商运营、美工、选品调研时，商品详情页的图片总是分散在页面各个位置，右键保存不仅慢，还经常拿到带水印的缩略图。

📸

图片分散难保存

商品图、细节图、SKU图混在长页面里，一张张右键保存耗时费力。

🔍

懒加载抓不到

很多电商站用懒加载，不滚动就不加载，手动保存容易漏图。

📐

格式不统一

原图是 webp / jpg，后期还需要统一转格式，额外增加工作量。

核心功能

⚡

一键提取

自动扫描页面所有商品图，兼容 srcset、data-src、背景图等多种懒加载方式。

🧹

智能过滤

自动排除图标、logo、占位图、1×1像素追踪图，只保留真正有用的商品图。

🖼️

集中预览

提取后自动打开新页面，网格布局展示所有图片，尺寸、序号一目了然。

✅

自由勾选

支持全选、反选、单选，只下载你真正需要的图片，不浪费空间。

🖼️

统一 PNG

通过 canvas 自动把 webp / jpg 转为 PNG 格式，无需二次处理。

📦

批量下载

一键批量保存，文件名自动编号（商品图_001.png、商品图_002.png...）。

4 步完成安装

1

下载插件压缩包

从 GitHub 下载代码并解压到本地文件夹，记住解压路径。

2

打开扩展管理页

Chrome 地址栏输入 chrome://extensions 回车。

3

开启开发者模式

打开页面右上角的「开发者模式」开关。

4

加载已解压的扩展

点击「加载已解压的扩展程序」，选择刚才解压的文件夹即可。
